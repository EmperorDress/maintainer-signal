A small OSS toolkit for issue priority, PR risk summaries, maintainer questions, and release-note drafts. It works offline by default and can optionally use OpenAI when maintainers enable it.

Pull requests

Surface review risk

Highlight security, breaking-change, dependency, CI, docs, and test signals from the context maintainers already review.

Releases

Draft notes quickly

Group conventional commits into readable release sections, ready for a maintainer to edit and publish.

Dry-run first

The CLI and action produce deterministic output without an API key. OpenAI usage is opt-in through repository secrets.

Conservative permissions

Workflow examples request only the permissions needed to read repository context and optionally write a comment.

No code mutation

Reports are advisory. Maintainer Signal never pushes commits, rewrites branches, or edits pull requests.
